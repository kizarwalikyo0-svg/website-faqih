Pengertian HTML

HTML (HyperText Markup Language) merupakan bahasa Markup standar yang digunakan untuk membuat dan menyusun halaman website.

  • HTML bukan bahasa pemrograman.
  • HTML tidak bisa berpikir, menghitung, atau mengambil keputusan.
  • Tugas HTML: mengatur struktur konten di halaman web.
  • HTML menggunakan tag untuk menandai elemen-elemen di halaman web.

Sejarah HTML

HTML adalah singkatan dari HyperText Markup Language, yaitu bahasa markup standar untuk membuat dan menyusun halaman web. Bukan bahasa pemrograman, melainkan bahasa penanda yang mengatur struktur konten website.

Awal Mula HTML

HTML pertama kali dikembangkan oleh Tim Berners-Lee pada tahun 1991, saat bekerja di CERN (Organisasi Riset Nuklir Eropa). Tujuannya memudahkan ilmuwan berbagi dokumen melalui internet.

Versi awal HTML sangat sederhana, hanya mendukung: <html> <head> <body> <p> <a>

Perkembangan HTML

2.0

HTML 2.0

📅 1995

Versi standar resmi pertama oleh IETF. Mendukung form sederhana: input teks dan tombol.

3.2

HTML 3.2

📅 1997

Dikembangkan W3C. Menambahkan dukungan tabel, script, dan peningkatan tampilan.

4.0

HTML 4.01

📅 1999

Sangat populer & bertahan lama. HTML dipisahkan dari tampilan — desain pakai CSS.

5

HTML5

📅 2008–2014

Perubahan besar: multimedia tanpa plugin, canvas, semantic tags, aplikasi web modern.

Now

HTML Sekarang

📅 Masa Kini

Dipelihara W3C & WHATWG. Fondasi utama web modern bersama CSS dan JavaScript.

Fungsi HTML

HTML berfungsi membuat dan menyusun struktur halaman website agar bisa ditampilkan browser.

  • Menampilkan teks (judul, paragraf)
  • Menampilkan gambar
  • Membuat tautan / link
  • Menyusun tabel, daftar, formulir, dll
  • Mengintegrasikan multimedia (video, audio)
  • Membuat form input (login, pendaftaran, dll)

Cara Kerja HTML

  1. Developer menulis kode HTML.
  2. File disimpan dengan ekstensi .html.
  3. Browser membuka file HTML.
  4. Browser membaca & menerjemahkan tag HTML.
  5. Konten ditampilkan sebagai halaman web.

Tag dalam HTML

Tag adalah komponen dasar HTML untuk memberi instruksi ke browser tentang cara menampilkan konten. Ditulis dengan tanda kurung sudut < >.

Struktur Tag

  • Tag pembuka → <p>
  • Isi konten → teks, gambar, dll
  • Tag penutup → </p>
<p>Ini adalah paragraf</p>

Jenis Tag

1. Tag Berpasangan

  • <p>...</p>
  • <div>...</div>
  • <h2>...</h2>

2. Tag Tunggal (Self-Closing)

  • <br> → pindah baris
  • <hr> → garis horizontal
  • <img> → menampilkan gambar

Tag & Atribut

<img src="gambar.jpg" alt="foto">
  • src → sumber file
  • alt → teks alternatif

Contoh Kode HTML

<!DOCTYPE html>
<html>
<head>
  <title>Contoh Kode</title>
</head>
<body>
  <h1>Halo Dunia!</h1>
  <p>Ini adalah paragraf pertama.</p>
  <a href="halaman.html">Klik di sini</a>
</body>
</html>

Kesimpulan

Tag adalah elemen inti HTML. Tanpa tag, browser tak bisa memahami struktur halaman web. Memahami tag = langkah pertama wajib dalam belajar web development.

HTML berdampingan dengan CSS dan JavaScript menjadi fondasi utama pengembangan website modern yang wajib dipahami setiap developer.
